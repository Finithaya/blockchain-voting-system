🗳️ Blockchain-Based Voting System

A secure, transparent, and tamper-proof voting system using Blockchain concept.

✨ Features

- 👤 One voter can vote only once
- 🔐 SHA-256 hashing for each vote
- 📊 Real-time vote counting
- ⛓️ Blockchain validation to detect tampering

🛠️ Technologies Used

- ☕ Java
- 🗄️ MySQL
- 🌐 HTML
- 🎨 CSS
- ⚡ JavaScript

🔄 How it Works

1. 📝 Voter registers and logs in
2. 🗳️ Voter casts a vote
3. 🔗 Vote is stored as a block with SHA-256 hash
4. 👨‍💼 Admin can view results and verify blockchain
